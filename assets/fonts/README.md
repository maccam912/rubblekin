# Bundled UI fonts

Rubblekin uses Atkinson Hyperlegible Regular for body text and Bold for screen headings. Both are embedded in the client so menus work offline and have the same letterforms on desktop and Android.

The fonts are from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegible), copyright 2020 Braille Institute of America, Inc., under the [SIL Open Font License](OFL.txt). The existing license covers both weights. Bold was added on October 10, 2026 from `AtkinsonHyperlegible-Bold.ttf` in that directory (version 1.006).

Prefer words over decorative arrow glyphs when the bundled fonts do not contain a character.
